An object-oriented foundation for the PressFlow WordPress plugin.

== Description ==

PressFlow currently provides only a scalable, maintainable plugin foundation. No business features are included in this release.

== Installation ==

1. Upload the `pressflow` directory to `/wp-content/plugins/`.
2. Activate PressFlow through the Plugins screen in WordPress.
